HOTELER의 첫 제품은 예약몰이 아니라 전 세계 체인·브랜드 호텔을 한곳에 모으는 호텔 데이터베이스입니다. 그룹, 브랜드, 로열티 프로그램, 국가와 도시를 넘나들며 찾고 최종적으로 각 호텔의 공식 홈페이지로 연결합니다.

이 v0.2는 구조 검증용 샘플입니다. 실제 서비스 단계에서는 각 그룹의 공식 호텔 디렉터리에서 호텔명·브랜드·좌표·공식 URL·운영 상태를 정규화해 수만 개 단위로 적재하는 것이 핵심입니다.

개별 호텔

호텔명, 브랜드, 위치, 로열티, 공식 링크와 한국어 예약 체크 정보를 하나의 영구 URL에 둡니다.

hoteler.kr/ ├── map/ ← 전 세계 지도 ├── groups/marriott/ ← Marriott 전체 ├── groups/hilton/ ├── brands/ritz-carlton/ ← 브랜드 전체 ├── brands/conrad/ ├── countries/japan/ ← 국가 ├── cities/tokyo/ ← 도시 ├── cities/tokyo/marriott/ ← 가치 있는 조합만 index ├── hotel/conrad-tokyo/ ← 개별 호텔 └── search/?brand=... ← 임의 필터 URL은 noindex

그리고 그 다음에 수익화가 붙습니다.

호텔 DB를 먼저 확보하면 우리 거래처가 있는 호텔은 공식 홈페이지 제휴 딥링크로 연결하고, 거래처가 없는 호텔도 데이터에서 빼지 않습니다. 그래야 HOTELER가 광고 목록이 아니라 실제 전 세계 브랜드 호텔 인덱스가 됩니다.

PHASE 1

Global Hotel Index

전 세계 체인·브랜드·호텔·좌표·공식 URL을 수집하고 변경사항을 정기 검증합니다.

PHASE 2

Affiliate Router

Marriott, Hilton, Accor, IHG 등 거래처가 있는 호텔만 우리 제휴 템플릿을 거쳐 공식 홈페이지로 이동합니다.

PHASE 3

HOTELER Partners

크리에이터별 링크 발급, SID, 클릭, 예약, 커미션 데이터를 얹어 플랫폼으로 확장합니다.
